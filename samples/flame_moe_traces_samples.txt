CMU-FLAME__FLAME-MoE-Traces -- raw samples
Raw folder (read-only): /projects/data/datasets/translation_data/Traces_datasets/OUTPUT/
20,920 parquet files, 1,000,000 rows each (~20.9 BILLION rows). NOT in any final SFT dataset.

WHAT THIS IS: routing traces of a Mixture-of-Experts (MoE) language model -- NOT chat / text data.
One row = one token passing through one MoE layer:
  indices  = the 6 experts (out of 64) the router picked for this token
  scores   = the router weight given to each of those 6 experts (highest first)
  token_id = id of the token in the model's vocabulary (often empty / None)
There is no user question and no assistant answer, so it cannot be used as SFT data.
